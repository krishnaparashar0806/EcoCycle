# EcoCycle Prototype

## Run
1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. Open Terminal.
4. Run:
   npm install
   npm run dev
5. Open the localhost URL shown by Vite.

## Demo roles
- User: dashboard, recycle, tracking, rewards, impact
- Recycler: incoming requests and status updates
- Admin: platform analytics

No database or backend is required for this prototype. Demo data is stored in browser localStorage.

## Suggested demo
1. Login as User.
2. Recycle Now.
3. Enter an item such as Old Laptop, 2.5 kg, choose a date.
4. Schedule pickup.
5. Open Track Pickup and use "Demo: Next Status" to move the request through the lifecycle.
6. Login as Recycler in another session/tab and demonstrate request management.
7. Login as Admin and show analytics.
8. Show Rewards and Environmental Impact.

## Important
EcoPoints and environmental impact numbers are prototype/demo rules. For production, use validated environmental factors, verified recycling partners, secure authentication, a real database, maps, notifications, and compliance checks.
